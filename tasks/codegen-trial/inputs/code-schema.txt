Implement a single, self-contained validation module in TypeScript using zod.

## File
Output exactly one file:

```file:schema.ts
// your implementation
```

## What to implement
A signup-form validator built on a zod schema, exporting all three of:

```ts
export const signupSchema = /* a z.object({...}) */;
export type Signup = z.infer<typeof signupSchema>;
export function validateSignup(input: unknown): ValidationResult;
```

Where `ValidationResult` is a discriminated union you define:

```ts
type ValidationResult =
  | { success: true; data: Signup }
  | { success: false; errors: Record<string, string> };
```

## Field rules (the schema)
- `email`: string, must be a valid email.
- `password`: string, minimum 8 characters, and must contain at least one letter
  and at least one digit.
- `age`: integer between 13 and 120 inclusive.

## validateSignup behavior
- Accept `unknown` input (do NOT type the parameter as `Signup`).
- On success: return `{ success: true, data }` where `data` is the parsed,
  typed value.
- On failure: return `{ success: false, errors }` where `errors` maps each
  failing field name to a human-readable message. Use zod's safe parsing (do not
  throw on invalid input); derive the field key from each issue's path.

## Acceptance criteria
- `validateSignup({ email: "a@b.com", password: "abcd1234", age: 30 })` →
  `{ success: true, data: { email: "a@b.com", password: "abcd1234", age: 30 } }`.
- `validateSignup({ email: "nope", password: "short", age: 5 })` →
  `{ success: false, errors: { email: <msg>, password: <msg>, age: <msg> } }`.
- `validateSignup(null)` and `validateSignup("x")` → `{ success: false, ... }`
  without throwing.

## Constraints
- Strict TypeScript: no `any`. The exported `Signup` type must be inferred from
  the schema via `z.infer`.
- Import zod as `import { z } from "zod";` (it is installed). No other packages.
- Output ONLY the `schema.ts` file block, no prose or tests.
