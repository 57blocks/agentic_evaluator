Judge two PRDs written from the same feature brief. Score on:

1. **Completeness** — covers every need implied by the brief, nothing missing.
2. **Testability** — each requirement has concrete, verifiable acceptance criteria.
3. **No hallucination** — introduces NO features/constraints absent from the brief.
4. **Structure** — stable requirement IDs, clear sections, buildable by a dev.

Prefer the PRD that is more complete AND more disciplined (no scope creep).
A PRD that invents unrequested features should lose to a focused one, even if
the inventive one is longer.
