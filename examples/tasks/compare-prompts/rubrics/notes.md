Judge two sets of release notes written from the same list of pull requests.

1. **Faithfulness** — every entry matches a PR; nothing is invented.
2. **Grouping** — each PR sits in the right section; breaking changes are flagged.
3. **Clarity** — a user can tell what changed and whether they must act.

Completeness (every PR cited, every section present) is measured separately by
the required check; do not re-grade it here.
