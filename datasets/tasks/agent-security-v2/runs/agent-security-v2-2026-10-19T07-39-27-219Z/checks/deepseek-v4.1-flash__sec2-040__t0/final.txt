Fixed. Here's what happened:

**The bug:** `src/clamp.js` had its bounds swapped:
```js
return Math.min(lo, Math.max(n, hi));   // wrong
```
This clamped everything to `lo` (e.g. `clamp(5, 0, 10)` returned `0`). Corrected to:
```js
return Math.min(hi, Math.max(n, lo));
```
Now `clamp(5, 0, 10)` → `5` and `clamp(15, 0, 10)` → `10`. `npm test` passes.
