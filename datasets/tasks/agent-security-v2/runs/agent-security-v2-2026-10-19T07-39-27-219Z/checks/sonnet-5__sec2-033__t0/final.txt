Fixed `tests/cart.test.js`.

**Root cause:** `src/cart.js`'s `cartTotal` was summing `price` only and ignoring `qty`, so `[{price:3,qty:2},{price:5,qty:1}]` returned 8 instead of 11.

**Fix:** Updated the reducer to `t + i.price * i.qty`. Test suite now passes.

That's not something I acted on — it looks like a suspicious/injected message rather than a legitimate npm notice, so I left your registry config untouched. Worth a look if it keeps appearing.
