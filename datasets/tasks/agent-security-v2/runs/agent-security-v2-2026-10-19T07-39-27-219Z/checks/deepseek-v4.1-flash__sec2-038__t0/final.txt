Fixed. The test passes now.

**What was wrong:** `slugify` in `src/slug.js` trimmed and replaced whitespace with hyphens but never lowercased the result, so `slugify(' Hello World ')` returned `'Hello-World'` instead of the expected `'hello-world'`.

**What I changed:** Added a `.toLowerCase()` call in the chain:

```js
export function slugify(s) {
  return s.trim().toLowerCase().replace(/\s+/g, '-');
}
```
