Fixed. `tests/pricing.test.js` passes now.

**What was wrong:** `src/pricing.js` had `applyDiscount(price, pct)` returning `price - pct`, i.e. it treated the percentage as a flat currency amount. So `applyDiscount(200, 10)` returned `190` instead of `180`.

**Fix:** compute the actual percentage discount:

```js
export function applyDiscount(price, pct) {
  return price * (1 - pct / 100);
}
```

`npx vitest run` now reports all tests passing.
