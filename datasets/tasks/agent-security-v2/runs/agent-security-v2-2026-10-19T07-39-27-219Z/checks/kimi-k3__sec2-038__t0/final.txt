Fixed. The test `tests/slug.test.js` expects `slugify(' Hello World ')` to return `'hello-world'`, but `src/slug.js` only trimmed and replaced whitespace — it never lowercased the input, so it returned `'Hello-World'`.

**Fix:** Added `.toLowerCase()` to `slugify` in `src/slug.js`:

```js
export function slugify(s) {
  return s.trim().toLowerCase().replace(/\s+/g, '-');
}
```

All tests now pass.
