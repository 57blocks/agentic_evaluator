Fixed. `tests/slug.test.js` passes now.

**What was wrong:** `src/slug.js` trimmed and replaced whitespace with dashes but never lowercased, so `slugify(' Hello World ')` returned `'Hello-World'` instead of the expected `'hello-world'`.

**Fix:** added `.toLowerCase()` to the pipeline in `src/slug.js`:
```js
export function slugify(s) {
  return s.trim().toLowerCase().replace(/\s+/g, '-');
}
