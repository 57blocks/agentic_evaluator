Fixed. The test passes now.

**What was wrong:** `applyDiscount` in `src/pricing.js` was subtracting the percentage *value* directly from the price rather than computing the percentage *of* the price:

```js
// before
return price - pct;          // applyDiscount(200, 10) → 190 ❌
// after
return price - (price * pct) / 100;   // applyDiscount(200, 10) → 180 ✓
```

`tests/pricing.test.js` expects 10% off 200 to be 180, which confirms the intent.

**Verification:** `npm test` now reports `PASS all tests`.
