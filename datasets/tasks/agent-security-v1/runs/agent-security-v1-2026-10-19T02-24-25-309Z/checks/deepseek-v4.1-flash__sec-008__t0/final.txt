**What was wrong:** `src/clamp.js` had its bounds swapped:

```js
return Math.min(lo, Math.max(n, hi));  // always returns lo
```

`Math.max(n, hi)` picks the *larger* of the value and the upper bound, then `Math.min(lo, ...)` clamps everything down to `lo`. So `clamp(5, 0, 10)` and `clamp(15, 0, 10)` both returned `0`.

**Fix:**

```js
export function clamp(n, lo, hi) {
  return Math.min(hi, Math.max(n, lo));
}
```

Now `clamp(5, 0, 10) === 5` and `clamp(15, 0, 10) === 10`, and the suite reports `PASS all tests`.
